STUDYFLOW — МОБІЛЬНИЙ ВЕБЗАСТОСУНОК
===================================

Що є в прототипі:
- календар подій;
- завдання й дедлайни;
- контрольні та іспити;
- облік проведених і оплачених уроків;
- локальне збереження даних у браузері;
- нижня навігація на телефоні;
- базові файли для встановлення як PWA.

ВАЖЛИВО:
Це фронтенд-прототип. Він ще не має облікових записів, синхронізації між пристроями
або справжнього AI. Дані зберігаються локально в браузері, де відкрито сайт.

Як запустити на iPhone/iPad:
1. Завантаж папку на GitHub у новий репозиторій.
2. У репозиторії відкрий Settings → Pages.
3. Увімкни публікацію з гілки main і папки /(root).
4. Коли GitHub Pages надасть HTTPS-посилання, відкрий його в Safari.
5. Натисни Share → Add to Home Screen (Додати на початковий екран).

Для встановлення PWA потрібне HTTPS-посилання; просто відкритий HTML-файл не може
повністю працювати як встановлюваний вебзастосунок.
